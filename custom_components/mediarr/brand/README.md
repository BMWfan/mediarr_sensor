# Mediarr branding

The turquoise clapperboard uses Material Design Icons `movie-open-outline`
by Pictogrammers (Apache 2.0; see LICENSE-MaterialDesign.txt).
Colour: `#03a9f4`. SVG sources and transparent PNG exports are included.
Icons: 256/512 px. Logos: 480×128 / 960×256 px. Dark variants use light text.

Home Assistant can use integration-local brand assets on supported versions.
HACS currently loads integration list icons from the central Home Assistant
brands service; these files alone do not register Mediarr there. Submission to
`home-assistant/brands` under `custom_integrations/mediarr` is still needed.
HACS uses a fixed category icon for dashboard cards, so the card repository's
branding is for its README and project assets, not a custom HACS list icon.
