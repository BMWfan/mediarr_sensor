# Mediarr branding

The turquoise clapperboard uses Material Design Icons `movie-open-outline`
by Pictogrammers (Apache 2.0; see LICENSE-MaterialDesign.txt).
Colour: `#03a9f4`. SVG sources and transparent PNG exports are included.
Icons: 256/512 px. Logos: 480×128 / 960×256 px.
Dark variants use the Home Assistant `dark_` filename prefix and light text.

Since Home Assistant 2026.3, custom integrations provide their images locally
in `custom_components/<domain>/brand/`. New custom integration submissions to
`home-assistant/brands` are no longer accepted. No central registration is needed.
See https://contributors.home-assistant.io/blog/2026/02/24/brands-proxy-api/.

Marketplace pre-installation icon discovery depends on the marketplace/client
and on assets being present in the integration's latest published release.
Do not assume every HACS version displays local assets before installation.
HACS dashboard cards use a category icon; the card repository's branding is
for its README and project assets, not a configurable HACS list icon.
